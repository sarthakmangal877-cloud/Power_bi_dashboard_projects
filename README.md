Bike Store Sales Analysis Dashboard | Power BI Project
📌 Project Overview

This project is a complete sales analysis dashboard built using Power BI for a Bike Store business. The dashboard provides meaningful insights into sales performance, customer behavior, product trends, and revenue analysis.

The main objective of this project is to transform raw business data into interactive visual reports that help stakeholders make data-driven decisions.

📊 Dashboard Features

The Power BI dashboard includes:

📈 Sales Performance Analysis
🛒 Product Category Analysis
🌍 Regional Sales Insights
👥 Customer Analysis
📅 Time-Based Sales Trends
💰 Revenue & Profit Analysis
📦 Order Quantity Tracking
🔍 Interactive Filters & Slicers
🛠️ Tools & Technologies Used

Power BI Desktop,
Power Query,
DAX (Data Analysis Expressions),
Data Modeling,
Excel / CSV Dataset.

📈 Key Business Insights

Identified top-performing product categories.
Analyzed monthly and yearly sales trends.
Discovered high-revenue generating regions.
Tracked customer purchasing patterns.
Compared revenue and profit performance.
Evaluated overall business growth using KPIs.

📊 Dashboard KPIs

The dashboard tracks important business metrics such as:

KPI	Description
Total Sales	Overall revenue generated
Total Profit	Profit earned from sales
Total Orders	Number of orders placed
Quantity Sold	Total products sold
Top Products	Best-selling products
Customer Insights	Customer purchase behavior
